0. 게임 개요

0.1 장르와 핵심 컨셉

요미 키우기는 모바일 방치형(Idle) RPG입니다.
플레이어는 "요미"라는 캐릭터를 육성하며, 자동 전투 시스템을 통해 스테이지를 클리어합니다. 게임을 하지 않는 동안에도 오프라인 보상이 축적되어 진행이 이어집니다.

0.2 핵심 게임 루프

┌─────────────────────────────────────────────────────────────┐
│  자동 전투 → 재화 획득 → 강화/가챠 → 더 강해짐 → 다음 스테이지  │
└─────────────────────────────────────────────────────────────┘
단계 내용 관련 요소
1. 전투 플레이어가 적을 자동 공격. 동료는 전투에 참여하지 않고 무기 효과만 제공 데미지 공식, 스킬 효과
2. 보상 적 처치 시 골드, EXP, 무기, 스킬 조각 드랍 드랍 확률, 레어도 보정
3. 성장 골드 강화 (Power, MaxHp, Critical 등 6종)
스탯 포인트 (레벨업 시 획득, 5가지 스탯 투자)
무기 장착 (기본 스탯 + 특수효과)
스킬 레벨업 (조각 소모, 효과 증가)
승급 (5단계, 스탯 배율 ×1~×15)
동료 테크트리 (4단계×2갈래 = 7노드/동료)
동료 무기 (해금 시 무기 효과 추가) 		강화 비용, 성장 곡선
4. 진행 스테이지 클리어 → 동료 해금 (20/40/60) → 승급 도전 → 특수 콘텐츠 적 HP 스케일링, 체크포인트

0.3 주요 시스템

시스템 설명 밸런싱 핵심
플레이어 주인공 요미. 근접 무기(Melee) 사용 Power, Critical, 스킬
동료 궁수/전사/법사 3종. Stage별 해금 무기 효과가 플레이어에 합산
무기 7단계 레어도 (Common~Ancient). 특수효과 보유 SkillType 26종
스킬 액티브/패시브 51개. 조각으로 레벨업 DPS 배율, 버프
스테이지 Normal 300 + 특수 143개 (Adventure 90, Dungeon 30, CompanionTech 18, Promote 5). 적 HP/저항 스케일링 진행 벽, 권장 레벨
경제 가차, 출석, 드랍, 오프라인 보상 수급/소비 균형

0.4 용어 정리

용어 설명
Power 공격력. 데미지 계산의 기본 스탯
특수효과 무기/스킬이 제공하는 추가 능력 (공격력 버프, 더블히트, 관통 등 26종)
효과 합산 플레이어와 동료 무기의 모든 특수효과가 합산되어 최종 수치 결정
레어도 무기/스킬의 등급 (Common → Uncommon → Rare → Unique → Legendary → Mythic → Ancient)
승급 Stone → Bronze → Iron → Silver → Gold 5단계. 스탯에 배율 적용
테크트리 동료별 성장 경로. 각 동료마다 4단계(0~3차) × 2갈래(0,1) 구성 = 7노드

1. 전투 시스템

전투는 플레이어만 직접 공격합니다. 동료는 전투에 참여하지 않으며, 무기 효과만 플레이어에게 제공합니다. 플레이어는 장착된 스킬을 순환하며 사용하고, 데미지는 공격력(Power), 치명타, 특수효과에 의해 결정됩니다. 모든 적을 처치하면 스테이지 클리어입니다.

1.1 전투 흐름

1. 스킬 시전 준비 (소리 재생)
2. 선딜 대기 ← 공격속도에 따라 단축
3. MP 소모 확인
4. 가장 가까운 적 선택
5. 데미지 계산 (Power × 스킬 배율 × 버프 × 크리티컬)
6. 적에게 피해 적용
7. 후딜 대기 ← 공격속도에 따라 단축
8. 반복

1.2 데미지 계산 공식

1단계: 기본 데미지
기본 데미지 = 스킬 배율 × 공격력(Power)

2단계: 버프 적용
데미지 = 기본 데미지 × (1 + AttBuff + Berserker + Rage)

3단계: 크리티컬
CritRate 발동 시 → 데미지 × CritDmg × (1 + CritDmgBuff)

4단계: DoubleHit
DoubleHit 발동 시 → 데미지 × 2

5단계: Resist/Penetration
유효 Resist = 적 Resist × (1 - Penetration)
최종 데미지 = 데미지 × (1 - 유효 Resist)

1.3 종합 DPS 공식

총 공격력 = 골드 강화 + 스탯 포인트 + 승급 배율 + 무기 기본 스탯

특수효과 합산 = 플레이어 스킬 효과 + 플레이어 무기 효과 + 동료들 무기 효과

최종 DPS = 총 공격력 × 크리티컬 배율 × 버프 배율 × 더블히트 배율 × 공격속도 배율 × 저항 감소율
동료 기여: 동료는 전투에 참여하지 않지만, 동료 무기의 특수효과가 플레이어에게 직접 합산됩니다.
동료 해금(Stage 20/40/60) 시 무기 슬롯 +1 효과로 파워 스파이크가 발생합니다.

1.4 전투 타이밍 파라미터

실제 전투에서는 DPS 이론값 외에도 이동 시간, 공격 딜레이, 처치 후 딜레이 등이 킬 사이클에 영향을 미칩니다. 이 파라미터들은 BattleManager.cs, Attackable.cs, SkillData.cs에서 정의됩니다.

핵심 타이밍 상수

파라미터 기본값 소스 설명
_defaultSpeed 2.5 BattleManager 플레이어 이동 속도 기준 (m/s)
_enemySpace 1.0 BattleManager 적 간 간격 (m)
_enemyPlayerDistance 1.5 BattleManager 공격 시작 거리 (m)
preDelay 0.2초 SkillData 공격 전 대기 (공속 반비례)
postDelay 0.2초 SkillData 공격 후 대기 (공속 반비례)
TargetKill 딜레이 0.5초 Attackable 처치 후 타겟 해제 대기
MoveSpeed 보정 1 + GetPWValue BattleManager 이동 속도 버프 적용
보스 제한시간 20초 BossTimerUI 시간 초과 시 전투 실패 (OnBossTimeLimit)
보스 HP 배율 ×8.3 StageInfo bossHp = enemyHp × 8.3

실제 킬 사이클 공식

실제 킬 시간 = DPS 이론 킬타임 + 이동 오버헤드 + 처치 후 딜레이

이동 오버헤드 = _enemySpace / (_defaultSpeed × (1 + MoveSpeed))
             = 1.0 / (2.5 × 1.0) = 0.4초 (기본값)

공격 딜레이  = (preDelay + postDelay) / AttackSpeed
             = (0.2 + 0.2) / 4.0 = 0.1초 (공속 4 기준)

처치 후 딜레이 = 0.5초 (고정)

예시: DPS 킬타임 2.0초 → 실제 킬타임 ≈ 2.0 + 0.4 + 0.5 = 2.9초
시뮬레이터: 밸런스 시뮬레이터는 위 타이밍 파라미터를 반영한 실제 킬타임을 계산합니다. 이동 속도, 공격 딜레이, 처치 후 딜레이가 모두 적용됩니다.

2. 스탯 시스템

플레이어의 전투 능력은 여러 스탯으로 구성됩니다. 각 스탯은 골드 강화, 스탯포인트 투자, 승급 등 다양한 방법으로 성장시킬 수 있으며, 각 강화 방법마다 비용과 효율이 다릅니다. 이 규형이 게임 경제와 진행 속도를 결정합니다.

2.1 스탯 종류 (StatusType)

스탯 설명 강화 방법
Power 공격력 골드, 스탯포인트, 승급
MaxHp 최대 체력 골드, 스탯포인트, 승급
HpRecover 초당 HP 회복 골드, 스탯포인트
Critical 치명타 확률 골드
CriticalDamage 치명타 피해량 골드, 스탯포인트, 승급
GoldAscend 골드 획득 증가% 스탯포인트

2.2 골드 강화 수치 (REINFORCE_VALUE_GOLD)

스탯 시작값 기본 증가 step stepInc
MaxHp 100 4 100 1
Power 10 1 100 0.5
HpRecover 1 0.2 200 0.1
CriticalDamage 1.2 0.01 100 0.01

2.3 스탯포인트 강화

레벨업 시 스탯포인트 1점을 획득합니다. (사용 가능 = 레벨 - 1 - 사용량)
골드 강화와 별도의 시스템으로, 다음 스탯을 강화할 수 있습니다.

스탯 효과 비고
Power 공격력 증가 골드로도 강화 가능
MaxHp 최대 HP 증가 골드로도 강화 가능
Critical 크리티컬 확률 증가 스탯포인트 전용
CriticalDamage 크리티컬 데미지 증가 골드로도 강화 가능
HpRecover 초당 HP 회복 골드로도 강화 가능

2.4 레벨업 경험치

필요 EXP = level² × 10 + level × 50
레벨 1→2 10→11 50→51 100→101
필요 EXP 60 1,500 27,500 105,000

3. 무기 시스템

무기는 기본 스탯(Power, CritDmg, Crit)와 특수효과(SkillType)를 제공합니다. 플레이어는 근접 무기(Melee)를, 동료들은 각각 Bow/Shield/Staff를 사용합니다. 레어도가 높을수록 기본 스탯이 강하고, 고티어 무기일수록 더 강력한 특수효과를 보유합니다. 동료의 무기 효과는 플레이어에게 직접 합산되므로, 동료 무기 선택도 중요한 전략 요소입니다.

3.5 무기 도감 (Weapon Book)

동일 세트의 무기를 획득할수록 공격력 보너스를 누적 획득합니다.

등록 조건

  • 무기 획득 시 자동 카운트 - 가챠/스테이지에서 무기 획득할 때마다 해당 세트 카운트 +1
  • 중복 획득도 카운트됨 (같은 무기 10번 획득 = 10 카운트)
  • 세트 내 총 획득 개수가 upgradeLevels[n]에 도달하면 해당 티어 보너스 획득

보너스 구조

  • upgradeLevels[]: 각 티어 도달에 필요한 총 획득 개수
  • upgradeStats[]: 각 티어에서 얻는 공격력 보너스 (누적 아님, 개별)
  • 예: Light 세트 - [40, 80, 120, 160, 200, 240, 280, 320] 획득 시 [24, 40, 80, 160, 320, 320, 320, 320] 보너스
  • 총 획득 200개 → 티어5 달성 → +24+40+80+160+320 = +624

4. 스킬 시스템

4.0 스킬 습득 및 강화

스킬 습득

플레이어 레벨에 따라 스킬이 해금됩니다. 해금된 스킬을 클릭하면 즉시 습득(skillLevel = 1)됩니다.

  • 레벨당 액티브 스킬 1개 + 패시브 스킬 1개 해금
  • SkillAcquireInfo.acquireLevel로 해금 레벨 정의

7.4 동료 파워 스파이크 반영 적 HP 공식

CompanionMultiplier:
  - Stage 1-19:  ×1.0 (동료 없음)

8.1 참고한 모바일 RPG → 본 게임 적용

참고 게임 참고한 개념 공식/메커니즘 본 게임 적용
Summoners War 방어력 감소 곡선 Defense가 높아질수록 피해 감소율 증가폭이 줄어듦
DamageReduction = DEF / (DEF + 1000)
→ DEF 1000일 때 50% 감소, 2000일 때 66% (체감 한계) 		Durability 최대 50% 피해 감소로 캡 설정

기본 CritDmg 150%, 장비로 250~300%까지 상승
엔드게임에서 CritRate 100%가 필수 (DPS 계산 기준) 		CritRate + CritDmg 분리 설계, 무기/스킬에서 공급

최대 12시간 누적 (VIP 레벨로 증가 가능)

Genshin Impact 데미지 공식 Damage = ATK × Talent% × (1 + DmgBonus)
× DEF_Mult × RES_Mult × Crit_Mult

DEF_Mult = (100 + CharLv) / (200 + CharLv + EnemyLv)
→ 같은 레벨일 때 ~50% 피해 관통

RES_Mult: 저항 0%일 때 100%, 마이너스 저항은 효과 절반 		레벨 기반 방어 계산 공식 참고
Honkai: Star Rail 방어력 공식 DEF_Mult = 1 - DEF / (DEF + 200 + 10 × Level)
→ 레벨 80, DEF 1000일 때 ~50% 피해 감소

방어 감소와 방어 관통은 가산 적용
합계 100% 도달 시 방어 무효화 (캡 존재) 		Durability 피해 감소 공식 설계 참고

11. 문제점 및 개선사항

11.1 발견된 문제

중요도 유형 문제 위치 설명 권장 조치
상 버그 무기 도감 보너스 미적용 PlayerStatus.cs Power 계산에 도감 보너스 누락 → 완성해도 전투력 0 증가 _power_Book 필드 추가
상 버그 승급 효과(Power) 미적용 PlayerStatus.cs _power_Promote 값 있으나 Power 계산 누락 → 승급해도 전투력 0 증가 Power 계산식 수정
상 버그 코스튬 가챠 비용 1다이아 CostumeUI.cs 1다이아로 설정됨 (의도치 않은 값) → 경제 붕괴 100~300 다이아로 수정
상 버그 동료 해금 조건 미적용 동료 시스템 스테이지별 해금 조건 있으나 시작부터 모든 동료 해금됨 → 해금 로직 미작동 해금 조건 체크 로직 수정
상 버그 가챠 확률 중복 정의 GachaSystem.cs RC에 tiers 값 있으나 코드에 하드코딩도 존재 → 어느 값이 적용되는지 불명확 하드코딩 제거, RC 값만 사용
중 밸런스 고등급 도감 완성 불가 GACHA_INFO Legendary/Mythic 확률 0.2~8.7% → 200h로 고등급 세트 완성 불가 확률 상향, 천장 시스템
중 밸런스 Mythic 확률 극악 GACHA_INFO 280회 이후 0.5% → 과금 없이 최종 무기 획득 불가 티어 구간 완화
중 밸런스 장기 잉여 무기 소모처 부재 무기/가챠 시스템 세트 완성 후 잉여 무기 용도 없음 → 저등급 누적 시 손실 회피·보상 무가치화 심리로 가챠 동기 저하 ① 저등급 N개 합성→고등급 1개, ② 잉여 무기 판매/분해 시스템
중 밸런스 도감 세트 보너스 불균형 WeaponBook SO Light만 의미있는 보너스(+1584), 나머지 세트는 티어당 +1 → 7세트 무의미, 도감 동기 편중 전 세트 보너스 밸런싱 또는 세트별 차별화된 효과 부여
하 개선 승급 효과 하드코딩 StatUI.Promote.cs 배율 값 하드코딩 → 변경 시 앱 재배포 필요 RC 또는 SO 분리
하 개선 코스튬 스탯 없음 TotalStatusUI.Costume.cs 외형만 변경 → 가챠 유인 부족 스탯 보너스 추가
하 개선 후반 스킬 콘텐츠 부족 SkillAcquireInfo Lv100 이후 스킬 2개만 → 후반 성장 목표 없음 스킬 진화 시스템: 새 스킬 습득 시 기존 스킬 진화, 효과/배율 상향
